## 阅读时需要区分的地方

| 位置 | 报告中的表述 | 当前代码或复核情况 |
| --- | --- | --- |
| 第 7 页，速度分母 | 当前时间与最低收益所在时刻之差 | 旧代码按回看行数计算；新版收盘模式按候选范围的实际时间跨度计算，均不等于最低点到当前时刻的间隔 |
| 第 8 页，基础阈值 | 默认 0.3 | 当前 CLI 默认 0.4；比对历史实验需显式对齐参数 |
| 第 10 页，表 1 均值 | 主组 137.8838、对照组 100.6800、差 37.2038 | 按表中十行已展示数值求平均分别为 141.4800、91.3740、50.1060；两处不一致，README 不沿用原均值结论 |
| 第 10 页，逐行差值 | 部分值与两列显示值直接相减相差 0.01 | 可能涉及显示精度；缺少未舍入的对应历史输出，故按原表保留，不擅自修正 |
| 第 13 页，前瞻 theta | 式中写为 `xi = min{3 alpha}` | 当前 `asof_close` 使用 `clip(50 × rise, 2, 30)`，不将该式视为等价定义 |
| 第 14–15 页，策略和样本 | 当日收盘开仓、提前平仓或第六日开盘退出；描述为 2023 年 | 当前只导出下一观测日开盘至指定日收盘的标签；提供的 `fast_test` / `fast_test3` CSV 实际为 2020 年，不据此声称重现报告中的 2023 年实验 |
| 第 14 页，约 500 支股票实验 | 1324 笔交易及收益汇总 | 本次未核验对应完整样本和回测输出，不作为当前版本业绩 |
| 因果和显著性讨论 | 多处使用“验证”“证明”“统计显著”等措辞 | 当前仓库提供描述性分析和案例，没有据此完成因果识别或独立样本的显著性验证 |

当前严格校验还会拒绝 `002642`、`002645` 中的非正价格记录；原表包含这两个标的，因此不能把当前有效样本汇总直接当作原表的重跑结果。具体方法调整见[版本溯源](../provenance.md)。

报告作为课程研究记录保留原貌，当前实现以代码和[方法说明](../methodology.md)为准。报告中的交易收益表不作为仓库的性能指标。
