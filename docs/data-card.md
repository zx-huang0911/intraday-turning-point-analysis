## 原始来源与授权状态

作者提供的历史数据来自 [CSDN 来源文章](https://blog.csdn.net/m0_46294856/article/details/126595863) 所指向的分享资源。该文章与作者提供的历史网盘链接一致。

核查时，未找到明确覆盖网盘行情数据的公开再分发许可。网页的文章转载许可不能据此推定为数据集许可；“可以下载”也不等于可以重新开源。这里记录来源，不把它认定为违规，也不替提供者作授权保证。

因此本仓库不镜像数据、不写入网盘提取码、不捆绑数据下载脚本。需要真实行情时，可向提供方确认研究、商业使用及再分发范围，或替换为自己已有授权的数据；转换为下述 CSV 即可分析。无需数据也可以完整运行合成演示和自动测试。

项目不要求签署额外的“数据协议”，也不能通过自拟协议将未知权利变成已授权。未来取得可再分发数据后，应另附提供方许可、版本、覆盖范围、获取方式、校验和及归属说明，不直接套用代码 MIT。

## 输入规范

UTF-8 CSV，一文件一标的；`000001_2020.csv` / `000001_2021.csv` 会合并为 `000001`。六位代码保留前导零；其他标的名仅允许英文字母、数字、下划线或短横线。输入目录只放行情 CSV，递归扫描会读取子目录。

| 列 | 要求 |
| --- | --- |
| `datetime` | 无时区的上海本地时间，精确到分钟；如 `2020-01-02 09:31:00` |
| `open,high,low,close` | 有限且严格正数；同一标的一致价格单位与复权口径 |
| `volume` | 有限且非负；单位由提供者定义，同一标的须一致 |

额外列不参与计算。当前实现不使用 `total_turnover`；VWAP 实际是 `sum(close × volume) / sum(volume)` 的分钟收盘价加权代理，并非按成交金额计算的严格 VWAP。

- 时间限制为 09:30–11:30、13:00–15:00；自动排序，拒绝重复时间、缺失值、非正价格和矛盾 OHLC。
- 推荐分钟收尾标签（常见 09:31–11:30、13:01–15:00）。主/对照窗口包含两端；半小时分段为 `(start, end]`，09:30 / 13:00 标签不计入分段。不同供应商需先明确 bar 含义。
- 240 bars/day 只是诊断参考，不是完整性保证。没有交易所日历核验；停牌、缺失交易日、错误日期不能仅靠行数识别。
- 日开盘/收盘取首条 open / 末条 close；缺少首尾 bar 时不能当作真实开收盘。收盘时点分析的解释依赖调用者确认完整日。
- 全日成交量为零时，VWAP 代理回退为收盘价算术平均；零成交量条数写入质量记录。
- 窗口内完全无记录时得分缺失，汇总分母剔除；部分缺失保留并报告 `window_bars` / `day_bars`，不填补。
- 跨日解释受复权、分红拆股、上市/退市、幸存者偏差影响，本工具不自动修正。

## 分享输出前需要知道

本仓库按作者提供的材料展示两张历史案例原图、研究报告图 1 及 PDF 原件；材料出处与处理方式见[报告说明](reports/README.md)。这不改变原始行情数据集的授权状态，也不向使用者授予其中第三方内容的再分发权。

自行生成的 HTML 会嵌入案例的分钟价格和成交量，分享前需确认数据提供方允许的使用范围。真实输入和本地批量输出仍建议保存在 `.local/` 或 `output/`，不直接打包进代码仓库。

环境和缓存也建议放 `.local/`。外接盘数据可直接读取，无需复制；本次原始行情仅本地用于算法核验，原始文件保持不变。
