# 版本溯源与整理范围

## 使用过的原始材料

| 材料 | 作用 | 是否放入公开仓库 |
| --- | --- | --- |
| `intraday_turning_point_project_with_strategy.zip` | 较新代码、原评分实现、策略实验审阅 | 否；原件本地保留 |
| `intraday_turning_point_project_v3.0` | 较旧代码、行情、历史输出与案例图片 | 否；原件本地保留 |
| `7-第10组-黄子欣史一诺韩鎔旭张钰浛.pptx` | 研究问题、方法、分工与解释边界 | 否；整理摘要并确认署名 |

v0.1.0 是基于这些材料的工程重构，**不是旧 v3.0 目录直接改名发布，也不声称完整复现全部 PPT 结论**。本地 `fast_test` 实际行情时期为 2020 年，没有标为其他年份。

## 保留、修正与新增

| 内容 | 处理 |
| --- | --- |
| 固定窗口、基线、低振幅常数、gamma、theta、超阈值分数和 | 回顾模式保留核心定义，参数显式化 |
| PPT 顺序加权叙述 | 以实际代码 `m × (gamma + theta)` 为复核目标，公开差异 |
| 旧 gamma 的 10/15 默认值分歧 | CLI 默认 15；旧逐日明细比对明确用 10 |
| 缺失窗口原本计为 0 | 改为 NaN 并记录有效分母 |
| 半小时时段共享端点 | 改成左开右闭，避免重复 |
| 旧案例图遗漏 11:30 bar | 新图保留全部有效输入 bar |
| 原行情非正价格 | 默认失败，显式跳过才排除整个标的 |
| 未来低点权重 | 保留并标明仅回顾；另增 `asof_close` 及信息边界测试 |
| 同日收盘信号/入场与简单收益汇总 | 不继承为策略业绩；改为下一观测日开盘起算的事件标签 |
| 原行业、市值分组与 panic 对偶实验 | 不纳入当前 CLI，避免将未复核实验当成当前能力 |
| 离线 HTML、数据校验、测试、安装包、CI | 本次新增工程工作 |

旧代码的当前行业查询不能保证历史时点一致，价格区间筛选也不能作为严格市值分组。PPT 中关于散户偏差、诱多和因果机制的讨论，公开版保留为待检验假设。

## 原算法一致性证据

使用较新压缩包的 `src/window_metrics.py` 中 `compute_daily_detailed_metrics`，与新版回顾模式主/对照窗口逐日得分比较。基础阈值 0.4、回看 10 行、前后 5 个观测日；八个通过严格校验的标的误差均在浮点舍入量级，见[验证说明](validation.md)。

只覆盖上述核心评分与本地样本，不包括所有老脚本、旧 PNG 逐像素一致性、PPT 全部结果或策略回测。原始行情与压缩包不在公开包内，历史对照需拥有这些材料才能独立重跑；合成演示和自动测试无需私人材料。
